Community review: how would you improve the experiment?

Help improve the experiment by explaining a method, an experience or a failure—not just voting on whether the hypothesis sounds plausible.

Added October 9, 2026 · Proposal stage · Draft for public review

Status: proposal for public review. This page contains no experiment results, community responses, installed-hardware claims or published findings. Hypotheses are not findings, and nothing here amends the current draft LOC-1 protocol.

There are no collected community results yet

This site does not yet contain community opinions, testimonials or polling statistics. The questions below are proposed for public participation. Personal experience can identify overlooked failure modes, but it cannot substitute for controlled measurements.

Important questions

  1. Is concurrent four-object readout worth the added calibration burden? Which failure would it detect that two objects would miss?
  2. How should timing skew be verified rather than assumed from timestamps?
  3. Which variable is most likely to imitate a position effect: temperature, fixtures, excitation, optical alignment or reference drift?
  4. Have you faced a similar multi-sensor or resonance problem? Describe the setup, what happened and the diagnostic evidence.
  5. What would you do differently now, and what practical improvement would you prioritize?
  6. What observation would count against your preferred explanation?
  7. What result and uncertainty would make an independent replication worthwhile?

Send a response

There is no on-site comment system or review database yet. Two real routes exist today:

  • Public: open an issue in the website repository. Issues are public, so leave out private contact details and any confidential or proprietary information.
  • Private: use the interest form (routed to contact@spheredesci.org). Read the privacy notice first. Private messages are not a public comment channel.

Prepare a review response locally

The form below only helps you organize a response. It creates a downloadable JSON draft in your browser. It does not submit anything to this site, publish a comment, collect an email address or send your text to a server. You can paste the contents into a GitHub issue or send the file privately.

Proposed publication rules

A live review system needs a privacy notice, consent, retention rules, moderation, spam protection and a real submission endpoint. Distinguish experience reports, suggestions, questions and independently documented evidence. Publish substantive criticisms as well as supportive responses. Do not expose personal data or present anecdotal reports as project findings.
