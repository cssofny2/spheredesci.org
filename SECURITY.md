# Security Policy

## Supported scope

Security reports are welcome for the current public website, its `/api/*` Worker
endpoints, and the repository's build and deployment code.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
[contact@spheredesci.org](mailto:contact@spheredesci.org). Include the affected
route or component, steps to reproduce, and any relevant impact. Do not post
unfixed vulnerability details in a public issue or discussion.

Please do not include passwords, access tokens, private keys, or other secrets
in a report.
