# SphereDeSci v2 preview

This is an isolated visual redesign scaffold on the `redesign-v2` branch. The existing root `index.html` and the `main` branch are not changed.

## Preview

To render this directory as a Cloudflare Pages site, configure a separate Pages project (or an isolated branch-specific build) with `site-v2` as its output directory. Do not change the production project's output directory without validating how it builds `main`. No Cloudflare Pages project has been configured by this commit.

`site-v2/index.html` uses a native stylesheet and small mobile-menu script, with no Tailwind Play CDN. Its navigation uses on-page anchors so the preview has no broken links. Proposed offerings, prices, financial reports, tokenization, facilities and active research should be verified before publication.

## Planned pages

- `desci/`: Open science and DeSci explanation
- `projects/`: Research projects and details
- `financials/`: Funding plan and verified updates
- `procurement/`: Equipment needs and vendor opportunities
- `store/`: Merchandise and precise allocation disclosures
- `spread-the-word/`: Advocacy playbook
- `careers/`, `facilities/`, `events/`, `faq/`, `blog/`, `contact/`, `sitemap/`: Additional content areas

No empty directories are committed; add pages as their copy is approved.
