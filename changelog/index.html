Versioning policy & source record

Website versions follow MAJOR.MINOR.PATCH and track public interface, documentation, publication platform, and infrastructure releases on spheredesci.org.

  • MAJOR — landmark public milestones for the website platform (for example, v1.0.0 marked the MDX research publication platform launch alongside live Protocol LOC-1 registration).
  • MINOR — new site sections, major navigation or visual upgrades, new research/Learn clusters, or security architecture additions.
  • PATCH — targeted wording corrections, bug fixes, metadata updates, or maintenance releases.

For commit-level diffs, see the GitHub commit history. For research milestones and the experimental roadmap, see Project updates.
