Publishing null results: why "no effect" is still a finding

A well-designed experiment that finds no effect still tells us something: it bounds how large any effect could be under the conditions tested.

Added October 14, 2026 · Educational explainer

Status: educational explainer. This page reports no experiment results. Project S.P.H.E.R.E. is at the proposal stage, hypotheses are not findings, and nothing here amends the draft LOC-1 protocol.

What is a null result?

A null result means the data did not show the effect that was hypothesized. It is not the same as proving the effect is impossible. A good null result reports an estimate and an uncertainty so readers can see what sizes of effect were ruled out.

The publication-bias problem

If journals and researchers favor positive results, the visible literature overstates how often effects exist, and other teams waste time repeating dead ends. Reporting nulls corrects the record.

How to report one well

  • State the smallest effect of interest in advance.
  • Report the effect estimate and its uncertainty, not only a p-value.
  • Describe the conditions, equipment and limits of sensitivity.
  • Share the data so others can re-analyze.

S.P.H.E.R.E.'s commitment

The research charter commits the project to publish its results whichever way they fall. Until any measurements exist, no result of any kind, positive or null, is claimed. Related: replication crisis.
